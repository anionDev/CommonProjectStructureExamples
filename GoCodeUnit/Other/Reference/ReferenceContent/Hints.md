# Hints

## Requirements

The following tools are required to build this codeunit:

- `cyclonedx-gomod` (installable with `go install github.com/CycloneDX/cyclonedx-gomod/cmd/cyclonedx-gomod@latest`)
- `docfx`
- `git`
- `go` (including `gofmt`, which is part of a usual go-installation)
- `python`
- `reportgenerator`
- `scriptcollection`

## IDE

The recommended IDE for this codeunit is [Visual Studio Code](https://code.visualstudio.com/) with the [Go-extension](https://marketplace.visualstudio.com/items?itemName=golang.Go).
