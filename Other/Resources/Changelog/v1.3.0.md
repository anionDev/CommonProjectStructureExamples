# Release notes

## Changes

- Migrated all codeunits to version `3.0.4` of the CommonProjectStructure (updated the codeunit- and constant-files accordingly).
- Updated GRYLibrary to v2.1.7.
- Added a `NuGet.config` to every .NET-codeunit which restricts the package-sources to nuget.org via a package-source-mapping.
- Updated the build- and tool-images (for example the SCBuilder-image used by the build-pipeline).
- Added a codespell-configuration (`.codespellrc`) for spell-checking.
- Updated the visual-regression-baseline-specification and renamed the baseline-images and their test-references to the new `<theme-mode>_<name>`-form (for example `light_user_settings_page` instead of `light-user-settings-page`).
- Updated the common-projects-structure-architecture-specification and the findings-table in `Other/Reference/Reference.md` (added a `Priority`-column).
- Added `SpringAPI` as the example for a Spring-Boot-web-API-application, which provides the same example-endpoint as `DotNetWebAPICodeUnit`, and `SpringAPIContainer`, which packages it into an OCI-image based on `eclipse-temurin` (defined by the entry `Java` of `.ScriptCollection/OCIImages/ImageDefinition.csv`).
