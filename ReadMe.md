# CommonProjectStructureExamples

## Purpose

The `CommonProjectStructureExamples`-repository contains examples how to implement/use the [Common project structure](https://github.com/anionDev/ProjectTemplates/blob/main/Conventions/RepositoryStructure/CommonProjectStructure/CommonProjectStructure.md) for different programminglanguages/projecttypes.
