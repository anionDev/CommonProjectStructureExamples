# DartLibraryCodeUnit

## Purpose

`DartLibraryCodeUnit` is the demonstration-codeunit for a Dart-library. It shows which shape such a codeunit
has in a repository which implements the CommonProjectStructure, not a realistic library: its only public type
(`Awesome`) is the one generated by `dart create --template=package`.

`DartLibraryCodeUnit` is built via `TFCPS_CodeUnitSpecific_Flutter` (from ScriptCollection), which is also used
for a plain Dart-package (see `Other/Build/Build.py`, whose build-target-list is empty because the codeunit has
no native build-target). Unlike `FlutterCodeUnit`, its `pubspec.lock` is deliberately not committed, because a
library-package should be tested against the dependency-versions its own `pubspec.yaml` allows, not against one
fixed set of resolved versions (see [Dart's guide about private files](https://dart.dev/tools/pub/private-files#pubspec-lock)).

## Structure

- `dart_library_code_unit` contains the Dart-package itself: `lib` (the public api and its implementation in
  `lib/src`), `test` (the testcases), `example` (a minimal usage-example) and `pubspec.yaml`.
- `Other` contains the scripts and the configuration which the CommonProjectStructure defines.

## Build

The codeunit is buildable by using the command `scbuildcodeunits` to build the entire product which includes
this codeunit.
